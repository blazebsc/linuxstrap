General Settings

These settings dictate Linuxstrap's behaviour.

Sober Settings

Open the native Sober configuration window.

Close on Leave

Automatically close Sober when you leave an experience.

Allow Gamepad Permission

Enables the service to use gamepads or controllers.

Touch Mode

Configure touchscreen behaviour and mobile UI.

Use libsecret

Uses libsecret for storing the session cookie instead of plaintext.

Show Discord RPC

When enabled, Linuxstrap will display the current experience you're playing on Discord.

Discord RPC Join Button

Display a button on your Discord profile allowing others to join your game.

Show Server Location

Displays an indicator showing the region of your current server.

Rendering Parameters

These settings control how rendering is handled by Sober.

Graphics Optimization Mode

Changes the fidelity level used by Roblox's rendering engine.

Rendering Backend

Only modify if you have issues with Vulkan.

Maximum FPS

If you have VSync enabled, this will be ignored.

Enable HiDPI Scaling

Scale the rendering properly on high-resolution displays.

Advanced Parameters

Do not modify these settings if you aren't aware of what they do.

Enable GameMode (FeralMode)

Request the system to allocate more resources to Roblox.

Use Console Experience

Force Roblox to load the Xbox/Console user interface.

FastFlags Presets

Easily modify specific engine behaviors hidden from normal users.

Preferred Lighting Technology

Forces the game to render using a specific lighting engine phase.

Preferred Texture Quality

Overrides the texture resolution of the game.

MSAA (Anti-Aliasing)

Smooths out jagged edges on 3D models.

Disable Bubble Chat

Turns off the new bubble chat from chat service entirely.

Disable Player Shadows

Improves performance by removing rendering shadows for players.

Custom FastFlags

Add specific FFlags overrides here.
